🔥 Scorch system map

One daemon.
Two execution paths.

Scorch keeps clients thin and places scraping, metasearch, browser rendering, crawl jobs, and network policy inside a single Rust service.

Core runtime Network Search Jobs & data
01 / CLIENT BOUNDARY

The client stays small

scorch only speaks HTTP. It never links the engine, API server, metasearch, Obscura, or Chromium.

02 / FETCH FIRST

Pay for rendering only when needed

Static pages use direct HTTP. JavaScript pages and screenshot requests move through the browser manager.

03 / SERVER POLICY

Requests cannot escape policy

Obscura is the default. Chromium works only when the operator explicitly includes it in the browser allowlist.
